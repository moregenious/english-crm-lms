# Step into the future — CRM & LMS для курсов английского языка

Веб-приложение для управления курсами английского языка «Step into the future» и администрирования учебного процесса.

---

## 🌟 Основные возможности

### 1. Архитектура базы данных и сущности
* **Ученики (Students)**:
  * ФИО ученика, контактный телефон
  * Информация о родителях (ФИО, телефон)
  * Класс (цифра и буква, например: *8-Б*)
  * Школа (номер/название)
  * Смена (*Первая / Вторая*)
  * Уровень английского (*Beginner, Elementary, Pre-Intermediate, Intermediate, Upper-Intermediate, Advanced*)
  * Текущий учебник (*Solutions, English File, Go Getter, Round-Up и др.*)
  * Заработанные баллы и история начислений
* **Учителя (Teachers)**:
  * ФИО учителя, телефон, email, специализация, закрепленные ученики
* **Расписание (Schedule)**:
  * День недели и время урока
  * Связка Учитель ↔ Ученик
  * Тема занятия и формат (*Очно / Онлайн*)
  * Статус урока (*Запланирован, Проведен, Отменен*)
* **Баллы и оценки (Points & Feedback)**:
  * Дата, категория (*ДЗ, Тест, Активность, Разговорный клуб, Экзамен*), количество баллов, комментарий и отзыв преподавателя

---

## 👥 Ролевая модель

1. 👑 **Кабинет Администратора (Владельца)**:
   * Сводный дашборд с ключевыми метриками (ученики, учителя, средний балл, ближайшие уроки, топ успеваемости).
   * **Управление учениками (CRUD)**: добавление новой анкеты со всеми полями, фильтрация по уровню и смене, поиск, редактирование, удаление и просмотр полного профиля с историей.
   * **Управление учителями (CRUD)**: создание профилей преподавателей, специализации, контактные данные.
   * **Интерактивное расписание**: недельная сетка и табличный вид, назначение уроков, быстрая смена статуса (*Запланирован / Проведен / Отменен*).
   * **Система баллов**: журнал оценок, начисление баллов с комментариями.
   * **Резервное копирование**: экспорт данных в JSON и сброс к демо-данным.

2. 🎓 **Кабинет Учителя**:
   * Персональное расписание: учитель видит только свои уроки с указанием уровня ученика и текущего учебника.
   * Список закрепленных учеников с карточками успеваемости (класс, смена, контакты родителей).
   * Быстрая отметка о проведении урока и выставление баллов.

3. 🎒 **Кабинет Ученика (Read-only)**:
   * Геймифицированный дашборд с накопленными баллами и шкалой прогресса до следующего уровня.
   * Текущий уровень языка и закрепленный учебник.
   * Карточка ближайшего запланированного занятия.
   * Полная история оценок за тесты и домашних заданий с комментариями учителей.

## 🚀 Запуск проекта

Так как проект выполнен на чистом современном стеке (HTML5, Vanilla CSS3, ES6 JavaScript Modules) с хранением данных в `LocalStorage`, его можно запустить любым локальным сервером.

### Запуск через Python:
```bash
cd english-crm-lms
python -m http.server 8080
```
Затем откройте в браузере: `http://localhost:8080`

---

## 🔄 Переключение между ролями
В правом верхнем углу интерфейса доступен переключатель **"Роль входа"**, позволяющий мгновенно переключаться между:
- Администратором
- Любым из преподавателей
- Любым из учеников
